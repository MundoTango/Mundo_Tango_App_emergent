## 🚀 Quick Commands

### File Protection
```bash
# Backup all docs to PostgreSQL
npm run backup-docs

# Restore from PostgreSQL
npm run restore-docs

# Check integrity (26 tests)
tsx scripts/test-file-protection.ts

# Sync working directory with git
git restore .
```

### Validation
```bash
# Pre-deployment checks
npm run predeploy

# TypeScript validation
npx tsc --noEmit

npm run dev
```
