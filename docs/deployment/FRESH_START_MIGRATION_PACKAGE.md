## 🛠️ **MIGRATION STEPS FOR NEW REPLIT**

### **Phase 1: Setup (30 minutes)**

1. **Create New Replit:**
   - Template: Node.js
   - Name: `mundo-tango-fresh`

2. **Initialize Project:**
   ```bash
   npm init -y
   npm install express cors compression
   npm install -D typescript @types/node @types/express
   npm install react react-dom wouter
   npm install @tanstack/react-query drizzle-orm postgres
   npm install -D vite @vitejs/plugin-react
   ```

3. **Copy Essential Files:**
   - Copy `01-ESSENTIAL-DOCS/` → `docs/`
   - Copy `02-DESIGN-SYSTEM/` → `client/src/`
   - Copy `03-DATABASE-SCHEMA/` → `shared/`
   - Copy `04-AUTHENTICATION/` → `server/` + `client/src/`
   - Copy `05-CORE-COMPONENTS/` → `client/src/components/`
   - Copy `06-API-ROUTES/` → `server/`

4. **Configure Environment:**
   ```bash
   # Add secrets in Replit:
   DATABASE_URL=<your-neon-postgres-url>
   JWT_SECRET=<random-256-bit-secret>
   SESSION_SECRET=<random-256-bit-secret>
   ```

---

### **Phase 2: Database Setup (15 minutes)**

1. **Install Drizzle:**
   ```bash
   npm install drizzle-orm drizzle-kit postgres
   ```

2. **Push Schema:**
   ```bash
   npm run db:push
   ```

3. **Seed Data (Optional):**
   ```bash
   npm run db:seed:test
   ```

---

### **Phase 3: Build Frontend (30 minutes)**

**Option A: Vite Build (Recommended if works)**
```bash
npm run build
```

**Option B: Emergency CDN (If Vite fails)**
- Copy `client/dist/index.html` from migration package
- Use `server/minimal-mt-server.js` as server

---

### **Phase 4: Start Server (5 minutes)**

```bash
# Development
npm run dev

# Production
npm start
```

## 🚨 **CRITICAL WARNINGS**

### **1. npm Install Order Matters:**
```bash
# CORRECT ORDER:
1. npm init -y
2. npm install <production-dependencies>
3. npm install -D <dev-dependencies>
4. npm install (to generate fresh lock file)

# WRONG:
# Don't copy package-lock.json from old project
# Don't copy node_modules
```

## 📞 **SUPPORT & TROUBLESHOOTING**

### **Common Issues:**

**1. "npm install fails"**
```bash
# Solution:
rm -rf node_modules package-lock.json
npm cache clean --force
npm install
```

**2. "Build fails with esbuild errors"**
```bash
# Solution: Use Emergency CDN
node server/minimal-mt-server.js
```

**3. "Database connection fails"**
```bash
# Check:
1. DATABASE_URL secret set correctly
2. Neon PostgreSQL running
3. Connection string format: postgresql://user:pass@host/db
```

**4. "Design system not applying"**
```bash
# Check:
1. client/src/index.css imported in main.tsx
2. Tailwind CSS configured
3. Dark mode class on <html> element
```
