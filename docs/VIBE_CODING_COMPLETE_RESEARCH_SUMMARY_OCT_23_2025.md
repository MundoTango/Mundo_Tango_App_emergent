### **5. File Editing Algorithms**
**File:** `docs/VIBE_CODING_FILE_EDITING_ALGORITHMS_OCT_23_2025.md` (partial)

**Performance Data:**
- Unified Diff: 61-72% success (best)
- SEARCH/REPLACE: 58-68% success
- Whole File: 20-25% success
- Prompt Only: 12-15% success

**Key Finding:** Algorithm choice matters 3-5x more than model choice!

**Implementations Covered:**
- Unified Diff (Aider-style, Git standard)
- SEARCH/REPLACE blocks (precise matching)
- Full file rewrite (small files only)
- Two-stage apply (Cursor's innovation)
- Order-invariant multi-diff (Cline's fix)

## 🎓 **Learnings from Open Source**

### **1. Algorithm > Model**

**Evidence:**
- Unified diff: 72% success (Claude)
- Whole file: 25% success (Claude)
- **Same model, 3x difference!**

**Takeaway:** Invest in file editing algorithms, not just better models

---

### **2. Repository Mapping is Essential**

**Aider's Innovation:**
- 100k LOC → 50k tokens
- Compact AST representation
- 2M+ token effective context

**Takeaway:** Can't skip this - AI needs to understand project structure

---

### **3. Self-Correction Loops Work**

**Pattern:**
```
Generate code → Run tests → Fail → AI analyzes → Fix → Retry → Pass
```

**Replit's Results:**
- 85% of issues fixed autonomously
- 92% first-time success rate (with retries)

**Takeaway:** Don't stop at first attempt, iterate until correct

---

### **4. Checkpoints Enable Experimentation**

**GPT Pilot's Approach:**
- Save after every major step
- Rollback in <5 seconds
- Free planning phase

**User Behavior:**
- Try ideas without risk
- Faster iteration
- Higher satisfaction

**Takeaway:** Safety nets encourage bold moves

---

### **5. Custom DSL > Function Calling**

**Replit's Choice:**
```xml
<boltAction type="file" path="App.tsx">
  [code]
</boltAction>
```

**vs Function Calling:**
```json
{"function": "write_file", "parameters": {...}}
```

**Results:**
- 2-3x faster execution
- More natural for AI
- Human-readable debugging

**Takeaway:** Consider XML/custom format over JSON
