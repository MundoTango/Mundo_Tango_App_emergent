## 🔴 GAP #1: SAVE BUTTON DISABLED - NO CHANGE TRACKING

### ROOT CAUSE
`UniversalSaveSystem.tsx` requires a `changes` array to enable the save button. This array is **initialized but never populated**.

### EVIDENCE TRAIL

**File:** `client/src/components/visual-editor/UniversalSaveSystem.tsx`
- **Line 24:** Component expects `changes: Change[]` prop
- **Line 46-53:** Save button disabled when `changes.length === 0`

**File:** `client/src/components/visual-editor/VisualEditorWrapper.tsx`
- **Line 60:** `const [changes, setChanges] = useState<Change[]>([]);`
- **Line 226-243:** Element selection updates `selectedElement` but NOT `changes`
- **CRITICAL:** `setChanges()` is **NEVER called** in the entire file

**File:** `client/src/components/visual-editor/InlineTextEditor.tsx`
- **Line 40-48:** Text edits call `onSave(text)` callback
- **ISSUE:** Callback updates DOM but doesn't append to `changes` array

### MISSING INTEGRATIONS

The `changes` array should capture:
1. **Content edits** - InlineTextEditor saves (currently untracked)
2. **Style changes** - Inspector panel modifications (currently untracked)
3. **Layout changes** - Element repositioning (currently untracked)
4. **Deletions** - Element removal (currently untracked)
5. **AI changes** - Code generated by vibe API (currently untracked)

### PROPOSED FIX

**VisualEditorWrapper.tsx** needs to intercept ALL edits:

```typescript
// 1. Hook into InlineTextEditor saves
const handleInlineTextSave = (element: HTMLElement, newText: string) => {
  const change: Change = {
    id: crypto.randomUUID(),
    timestamp: new Date(),
    elementSelector: element.id ? `#${element.id}` : getXPath(element),
    changeType: 'content',
    before: element.textContent,
    after: newText
  };
  setChanges(prev => [...prev, change]);
  element.textContent = newText;
};

// 2. Add MutationObserver for DOM changes
useEffect(() => {
  const observer = new MutationObserver((mutations) => {
    mutations.forEach((mutation) => {
      if (mutation.type === 'attributes') {
        // Track style/class changes
        trackStyleChange(mutation.target, mutation.attributeName);
      }
      if (mutation.type === 'childList') {
        // Track deletions
        trackDeletions(mutation.removedNodes);
      }
    });
  });
  
  observer.observe(document.body, {
    attributes: true,
    childList: true,
    subtree: true,
    attributeOldValue: true
  });
  
  return () => observer.disconnect();
}, []);
```

## 🔴 GAP #3: VIBE CODING NOT EXECUTING - CONTEXT DETECTION TOO RESTRICTIVE

### ROOT CAUSE
Vibe coding only executes if user has selected an element OR preview path is set. Keyword detection is also too narrow.

### EVIDENCE

**File:** `client/src/components/mrBlue/ChatInterface.tsx`

**Lines 526-541:** `detectAndExecuteCodeChanges()` function
```typescript

  // ❌ RESTRICTIVE: Only execute if element selected OR preview active
  if (!activeElement && !previewPath) return;
  
  // ❌ RESTRICTIVE: Only 14 keywords checked
  const codeKeywords = [
    'remove', 'delete', 'add', 'create', 'modify', 'change',

    'color', 'size', 'position', 'hide', 'show'
```
