## 🎯 **DOCUMENTATION STANDARDS**

### **All Documents Must Include:**
1. **Date:** When created/updated
2. **Purpose:** What problem does this solve?
3. **Status:** Active, archived, or to-restore
4. **Version:** Track major changes

### **Naming Convention:**
```
UPPERCASE_DESCRIPTION_DATE.md

Examples:
- AGENT_LEARNING.md (critical, no date)
- MB_MD_COMPREHENSIVE_ANALYSIS_OCT_19_2025.md
- PHASE_14_LCP_OPTIMIZATION_COMPLETION_REPORT.md
```

### **Protection Rules:**
- ✋ Never delete `.md` files without user approval
- ✋ Always archive instead of delete
- ✋ Update this index when adding new docs
- ✋ Use `npm run backup-docs` after major updates

## 📞 **RECOVERY PROCEDURES**

### **If Documentation Is Missing:**
```bash
# 1. Check PostgreSQL backup
npm run restore-docs

# 2. Check git history
git log --all --diff-filter=D -- "FILE_NAME.md"
git show COMMIT~1:FILE_NAME.md > FILE_NAME.md

# 3. Check archived folder
ls docs/archived/

# 4. Ask user if they have backup
```

### **If System Is Broken:**
```bash
# 1. Read AGENT_LEARNING.md for critical rules
# 2. Check MT_MASTER_REBUILD_PLAN.md for recovery plan
# 3. Use MB.MD methodology (Mapping first!)
# 4. Consult architect for root cause analysis
```
